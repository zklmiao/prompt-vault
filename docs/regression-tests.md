# Prompt Vault 全量回归测试计划（测试 Prompts）

> 基线：v0.1.9 @ `36d0e5b`（2026-10-29）。spec 来源：README 功能表/快捷键表、`docs/backlog.md`、AGENTS.md 硬性约定（仓库无独立 spec.md，以三者为准）。
> 执行环境分层：L0 静态检查 / L1 Node 单元测试 / L2 浏览器功能回归（`preview/` 夹具 + 浏览器自动化）/ L3 构建验证 / L4 打包冒烟与人工清单。
> 预览种子数据：`preview/mock-core.ts` 8 条（id 1–8，id1「代码审查助手」置顶 12 次复制，id2「周报生成器」置顶无统计，id3「翻译润色」5 次复制，id4–8 无统计）。

## 0. 执行纪律（硬约束）

- **不过度测试**：只测 README/backlog 声明的行为与数据安全约定；不测第三方库内部、不测纯样式微调、不重复覆盖同一代码路径。
- **不虚假 pass**：每条用例必须取得真实证据（DOM 文本、`window.__lastCopied`、`localStorage`、console 侦听、命令退出码），断言值与预期精确比对，禁止"看起来对"。
- **不虚假 fail**：出现 mismatch 时，先复核用例本身（预期值是否抄错）与环境（mock 状态是否被前序用例污染），重跑一次；仍失败才判定 fail，进入根因分析。
- **fail 处理（对应要求 g）**：先分析测试用例与场景是否合理 → 合理则定位根因（代码级）→ 输出「问题描述 / 根因 / 修复方案」→ 追加写入 `issues.md`。
- **阻塞切换（对应要求 h）**：前置用例 fail 导致依赖链不可执行时，切换到预先设计的互补分支继续（见 §3），并保持各组独立复位（刷新页面 + 清 localStorage 恢复种子态）。
- **数据安全**：全程不触碰真实 `data/prompts.json`；只与 `preview/` mock 与 `test-files/` 夹具交互。

## 2. L1 单元测试 Prompts（Node 直接执行 `regression/util.test.ts`）

- **U1 coerceItems 兼容性**：输入 `{prompts:[...]}`、裸数组、`null`、非对象项、字符串字段类型错误（title 传数字）、tags 含非字符串、lastValues 含非字符串值、copyCount 为负数/浮点/字符串、deletedAt 缺失 —— 断言逐字段纠偏且不抛错；旧数据（只有 v0.1.0 基本六字段）必须无损通过。
- **U2 coerceItems id/时间兜底**：缺 id 生成 uuid、缺 createdAt/updatedAt 填当前时间（两分钟内）。
- **U3 占位符提取**：`{{a}}`、中文变量、同名去重、`{{}}`空名、`{{{a}}}` 不匹配、`{{a}}}}` 尾随括号不匹配、名字含空格 trim。
- **U4 占位符填充**：留空键保持原文、同名只按一个键替换全部出现、值含正则特殊字符按字面替换。
- **U5 serializeDataFile**：输出含 `version:1`、两空格缩进、字段完整。
- **U6 时间**：`isNewer` 对坏字符串退回字典序、`newerIso` 缺失补位；`formatDate` 对非法 iso 返回原串。
- **U7 fuzzyMatch/matchPrompt**：完整子串高分、子序列命中、反序不命中、空查询 null、大小写不敏感、词首加分、跨字段加权（标题>标签>来源）、正文命中且标题标签未命中才生成 bodySnippet、片段边界（前 24 后 40、换行替换为空格、省略号）。
- **U8 extractPlaceholders**（同 U3 补充）：`bodySegments` 交替片段正确。
- **U9 formatHotkey**：`alt+shift+n→Alt+Shift+N`、`control→Ctrl`、`commandorcontrol→Ctrl`、`super→Win`、`arrowup→↑`、`f12`、单字符大写、未知多词首字母大写。
- **U10 isComposingEvent**：`isComposing=true`、`keyCode===229`、两者皆无返回 false（合成 nativeEvent）。
