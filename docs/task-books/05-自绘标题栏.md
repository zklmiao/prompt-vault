【任务】把 Prompt Vault 主窗口的默认 Windows 标题栏换成自绘标题栏。

【项目背景】项目在 <项目根目录>,Tauri 2 + React 19 + TS(Vite),Rust 代码在 src-tauri/src/lib.rs,前端在 src/。界面全中文,CSS 全部走 token(见 src/App.css 的 :root 与 :root[data-theme="dark"]),图标统一用 src/components/icons.tsx 里的内联 SVG(线性风格,16px,stroke=currentColor)。构建命令 npm run tauri build(NSIS 打包需要从 GitHub 下载工具,偶发超时,失败就重试同一条命令,本机缓存已就绪)。

【现状】
- 主窗口在 src-tauri/tauri.conf.json 配置,无 decorations 设置(即默认系统标题栏),1100x750,可缩放。
- 关闭行为:lib.rs 的 on_window_event 拦截 CloseRequested → 隐藏到托盘 + 首次弹提示,任何关闭路径都天然兼容。
- 快速拾取窗口 quickpick 已 decorations:false + transparent,前端按 window label 分流(src/window.ts),本次不受影响。
- 前端结构:src/App.tsx 渲染 header(搜索+按钮)、两栏主区;QuickPick.tsx 独立。

【需求与交互设计】
1. tauri.conf.json 主窗口加 "decorations": false,保留默认 shadow,不加 transparent(避免文字彩边)。
2. 新建 src/components/TitleBar.tsx,高 36-40px,只在主窗口渲染(main.tsx 分流即可,QuickPick 不渲染):
   - 左侧:16px 应用图标(用 /icon.png,public 下已有)+ 文字 "Prompt Vault"(13px,secondary 色)。
   - 中间:空白拖拽区,加 data-tauri-drag-region 属性;双击 = 最大化/还原(若 drag-region 不自带双击行为,自己 onDoubleClick 调命令)。
   - 右侧:三个窗口控制按钮(最小化 / 最大化还原 / 关闭),各 46x32,图标用 icons.tsx 新增 3 个线性 SVG;关闭按钮 hover 背景用 --danger(红底白字),其余 hover 用 --panel-hover。全部走 token,暗色自动适配。
3. 窗口操作统一走新增 Rust 命令(避免 JS 窗口权限配置):
   - win_minimize、win_toggle_maximize、win_close(close 内部就是 window.close(),会触发已有 CloseRequested 拦截 → 隐藏到托盘)。
   - 点击关闭 = 隐藏到托盘,与现有行为完全一致。
4. 无边框窗口的拖拽调大小依赖系统边缘,保持 resizable 默认;验证四边/四角可拖动缩放。

【实现要点】
- lib.rs:新增上述 3 个 #[tauri::command](参数 AppHandle),注册进 invoke_handler;前端 api.ts 加 3 个包装函数。
- App.tsx:在最顶部渲染 <TitleBar />(仅主窗口);App 的 .app 容器高度仍是 100vh,header 下移。
- 窗口最大化后双击还原、再双击最大化,状态由 toggle_maximize 处理,不要在前端自己维护。
- DRAG REGION 注意:按钮区域不能带 data-tauri-drag-region(否则点不动),只给空白容器加。

【边界与异常】
- 最大化状态下拖拽/双击行为正常;托盘唤回后窗口状态不变。
- 暗色/亮色两套主题下按钮对比度都清晰。
- 不要改 quickpick 窗口的样式与行为。

【不要做的事】
- 不要引入 UI 框架或图标库;不要改数据文件结构;不要动其他窗口逻辑。

【验收标准】
- npm run tsc --noEmit 通过;npm run tauri build 成功并刷新 releases/ 两份 exe。
- 冒烟启动进程存活;人工验证:拖动窗口、双击最大化/还原、最小化、关闭进托盘、托盘唤回、暗色下样式正常。
