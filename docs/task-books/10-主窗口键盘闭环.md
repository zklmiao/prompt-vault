【项目背景】项目在 <项目根目录>(Tauri 2 + React 19 + TS),版本 0.1.9。主窗口在 src/App.tsx;列表在 src/components/Sidebar.tsx;详情/编辑在 src/components/DetailPane.tsx;速查表在 src/components/CheatsheetModal.tsx;样式在 src/App.css(token 化,light/dark)。所有按键处理必须复用 src/util.ts 的 isComposingEvent()(IME 组字守卫)。禁止引入第三方库。

【现状(已核实,2026-10-29)】
- App.tsx 已有三处 window keydown:①Ctrl+N/Ctrl+F;②Esc 清多选 + Ctrl+A 全选(带 typing 与 modalOpen 守卫);③Ctrl+K 命令面板 + ? 速查表。
- 选择状态:selectedId(单选高亮,164 行附近)、selectedIds(多选)、filtered(463 行附近的模糊/排序结果);动作:handleCopy(884 行附近,自动识别占位符弹窗)、handleRowClick(544 行附近)、toggleSelected(533 行附近)、selectAllFiltered、clearSelection;编辑用 setMode({kind:"edit", id})。
- Sidebar 行是 div.row,onClick=onRowClick,内部有原生 checkbox(row-check,带 aria-label)与 row-copy 按钮;行目前无 tabIndex/role/id。
- 搜索框在 1276 行附近,只有 ref/value/onChange,无 aria 关联、无键盘处理。
- 全项目目前没有任何 ArrowDown/ArrowUp/Home/End 处理。
- 弹层标志:copyTarget、purgeTarget、importCandidate、batchPurgeOpen、settingsOpen、paletteOpen、cheatsheetOpen。
- 空态语义问题已修复(fbb6f0d),本任务不涉及。

【键位语义(必须逐条实现)】
1. ↑ / ↓:移动活动项。无活动项时 ↓ 选第一条、↑ 选最后一条;到达两端后停住(**clamp,不循环**)。
2. Home / End:跳到第一条 / 最后一条,并滚动到可见。
3. Enter:复制活动项(走现有 handleCopy,含占位符弹窗);**无活动项时只选中第一条,不复制**。不处理 PageUp/PageDown、j/k、Delete、F2(明确不做)。
4. Ctrl+E:进入活动项编辑态(仅主列表;回收站视图 no-op);无活动项时 no-op。
5. Space:仅当焦点在列表行(或行内非交互区域)时切换该行多选(等同勾选),preventDefault 防止页面滚动;在搜索框内 Space 正常输入,不拦截。
6. Esc 分层:弹层打开时由弹层处理(现状);否则若处于编辑态 → 退出编辑(setMode view)并把焦点移回搜索框;否则沿用现有“清空多选”。
7. Ctrl+A / Ctrl+F / Ctrl+N 保持现有语义不变。

【焦点与路由(实现重点)】
1. 新增第 4 个 window keydown effect(与现有三处分层,不合并):
   - 最前先 isComposingEvent(e) 返回;
   - 抽出派生变量 overlayOpen = !!(copyTarget || purgeTarget || importCandidate || batchPurgeOpen || settingsOpen || paletteOpen || cheatsheetOpen),overlayOpen 为真时直接返回;
   - 目标分类:isSearch = target === searchRef.current;isTextField = TEXTAREA 或 contentEditable 或 (INPUT 且 type 不是 checkbox/radio/button/submit);isSelect = tagName === "SELECT";isButton = BUTTON 或 INPUT type 为 button/submit;isCheckbox = INPUT type=checkbox。
   - 优先级:isSelect / isButton / isCheckbox → 全部放行给原生;isTextField 且非搜索框 → 放行;isSearch → 仅处理 ↑↓/Home/End/Enter/Ctrl+E;焦点在行或 body/root → 处理全部列表键。
2. 搜索框保持焦点时不抢焦点:↑↓ 只更新 selectedId(视觉高亮),Enter 复制,Ctrl+E 编辑——即 aria-activedescendant 模式。
3. 焦点在行上时(roving tabindex):↑↓ 除更新 selectedId 外,同步把 DOM 焦点移到新行;Enter 复制;Space 勾选;Ctrl+E 编辑。
4. 活动项定义:activeId = selectedId ∈ filtered ? selectedId : null。搜索过滤后活动项不存在时,Enter 不生效;按 ↓ 落到第一条。
5. 输入过程中不要自动选中第一条(避免误按 Enter 复制);只有 ↓/Home 才建立活动项。
6. 编辑态下方向键/空格归文本框(靠 isTextField 分支放行),Ctrl+Enter 保存、Esc 退出编辑(见键位语义 6)。

【可访问性(必须)】
1. Sidebar 列表容器:`role="listbox"`、`aria-multiselectable="true"`、`aria-label="收藏列表"`(或回收站时"回收站列表")、`id="pv-list"`。
2. 行:`role="option"`、`aria-selected={checked}`、`id={"pv-row-" + it.id}`;roving `tabIndex`:有选中项时仅选中行 0、其余 -1;无选中项时第一行 0、其余 -1(保证 Tab 能进入列表)。
3. 搜索框:`aria-controls="pv-list"`、`aria-activedescendant={activeId ? "pv-row-" + activeId : undefined}`;不要加 aria-expanded(列表常驻可见)。
4. 行内 checkbox 设 `tabIndex={-1}`(鼠标专用),保留 aria-label;键盘勾选走 Space。
5. 行 `onFocus` 时同步 selectedId(保证焦点与选中一致);行内按钮/checkbox 获得焦点时不触发该同步(避免点复制按钮改选中)。

【视觉与滚动(零新增像素)】
1. 仅新增 `.row:focus-visible` 轮廓(2px accent、outline-offset: -2px,不改变布局);不新增其他常驻元素。
2. 活动项变化后滚动跟随:`document.getElementById("pv-row-" + activeId)?.scrollIntoView({ block: "nearest" })`;不使用 smooth 滚动。
3. 不改变列表行现有信息密度与 hover 行为。

【边界与回归(逐条落实)】
1. 弹层优先:任何弹窗/面板打开时,列表键完全静默。
2. IME 组字期间全部忽略(已有工具)。
3. 排序下拉(SELECT)聚焦时 ↑↓ 改排序、Esc 关下拉,不导航列表;顺手把第二处监听的 typing 判定补上 SELECT(现存小 bug:下拉聚焦时 Esc 会误清多选)。
4. 行内复制按钮聚焦时 Enter 执行按钮,全局监听不得拦截;行内 checkbox 聚焦时 Space 走原生。
5. 过滤到空列表:Enter/Ctrl+E/Space 均 no-op;不报错。
6. 回收站:Ctrl+E no-op;Enter 复制、Space 多选、↑↓ 导航正常。
7. 保存/取消编辑后焦点回到搜索框(可在 Editor 卸载时聚焦 searchRef)。
8. 连续快速按键不丢步;按住不放按原生 repeat 处理,无需自建节流。
9. 不引入状态库、不重构既有三处监听(只允许补 SELECT 判定与复用 overlayOpen 的空值判断)。
