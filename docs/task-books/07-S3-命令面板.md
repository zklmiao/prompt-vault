【任务】S3 · 应用内命令面板 Ctrl+K + 快捷键速查表 ?。

【项目背景】项目在 <项目根目录>(Tauri 2 + React 19 + TS)。主窗口界面在 src/App.tsx(约 1100 行),已有全局按键监听两处(约 325 行 Ctrl+N/F;约 545 行 Esc 清多选 / Ctrl+A 全选)、模态互斥判定 modalOpen(copyTarget/purgeTarget/importCandidate/batchPurgeOpen/settingsOpen)、以及现成动作回调:startNew、newFromClipboard、handleImportPick、handleExport、toggleTrash、setSettingsOpen(true)、setSortMode("updated"|"recent"|"most")。主题状态目前在 ThemeToggle 组件内部(约 83-99 行)。所有按键处理必须复用 src/util.ts 的 isComposingEvent。样式走 CSS token;图标用 src/components/icons.tsx 的内联 SVG;禁止引入第三方库。Ctrl+K 与 ? 当前均未被占用(已核实)。

【前置改动(必须)】
1. 主题状态提升:把 theme/setTheme 移入 App(初始化沿用 theme.ts 的 currentTheme/applyTheme),ThemeToggle 改为受控组件(props: theme, onToggle),行为与外观不变。
2. 若 S1 已完成:复用 src/util.ts 的 fuzzyMatch;若尚未做 S1,则先在本任务内实现同样的 fuzzyMatch(签名一致,放到 util.ts),并在 backlog 备注“S1 可复用”。

【命令面板(Ctrl+K)】
1. 新建 src/components/CommandPalette.tsx:居中覆盖层(宽约 640,最大高 420),复用 App.css 的 qp-* 视觉(输入行 + 列表 + 空态),不套用 Modal 的标题栏;输入框 autofocus;点击遮罩、Esc、执行命令后关闭。
2. 分组命令(中文标签 + 关键词数组供搜索,匹配时高亮命中字符):
   收藏:新建 prompt(Ctrl+N)、从剪贴板新建(显示当前配置热键)、导入 JSON、导出 JSON、打开回收站/返回收藏列表;
   视图:切换主题(暗色/亮色动态文案)、排序:最近更新/最近复制/最常复制(当前项打勾)、快捷键速查(?);
   应用:打开设置(显示当前快速拾取热键)。
3. 键盘:↑↓ 循环(跨分组扁平化,分组标题不可选)、Enter 执行、Esc 关闭。所有按键先过 isComposingEvent 守卫。
4. 打开条件:Ctrl+K(非组字),且当前没有其他弹窗(copyTarget/purgeTarget/importCandidate/batchPurgeOpen/settingsOpen/cheatsheetOpen)时打开;palette 自身打开时再按 Ctrl+K 关闭。打开时记录并清空输入。
5. 动作映射:命令直接调用 App 现有回调;导入/导出前先关闭面板再触发(原生对话框);切换排序调用 setSortMode;打开设置 setSettingsOpen(true);回收站命令调用 toggleTrash 并关闭面板。
6. 状态:App 增加 paletteOpen 状态;把它加入 modalOpen 判定;同时给 Ctrl+N/F 处理器加 `if (paletteOpen || cheatsheetOpen) return;` 守卫,避免在覆盖层后面打开编辑器。

【快捷键速查表(?)】
1. 新建 src/components/CheatsheetModal.tsx,复用 src/components/Modal.tsx(自带 focus trap 与 Esc)。
2. 触发:keydown 的 event.key === "?"(即 Shift+/),且 isComposingEvent 为假、焦点不在 INPUT/TEXTAREA/contentEditable(复用多选处理器里同样的 typing 判定)、无其他弹窗时打开;速查表打开时按 ? 或 Esc 关闭。
3. 内容分组卡片(kbd 键帽样式用现有 token 新增 `.kbd` 类):
   全局:快速拾取(动态热键)、剪贴板新建(动态热键);
   窗口:Ctrl+N 新建、Ctrl+F 搜索、Ctrl+K 命令面板、Ctrl+Enter 保存、? 本速查表;
   编辑与列表:标签输入 Enter 添加、占位符弹窗 Enter 复制、↑↓/Enter/Esc(快速拾取)、Ctrl+A 全选、Esc 清除多选。
   动态热键通过 src/api.ts 的 getHotkeys() 读取(失败回退 alt+q / alt+shift+n),不要把热键写死。
   内容必须与当前真实行为一致;若发现某条不存在的行为,不要写进速查表。

【实现约束】
- 不改变既有快捷键语义;不引入新全局热键;所有新 keydown 先过 isComposingEvent。
- 面板/速查表视觉与现有设计语言一致(圆角、token 色、SVG 图标),暗色模式正常。
- 命令执行后焦点回到主窗口,不留下悬空 focus。

【边界与异常】
- 浏览器预览中 getHotkeys 会失败:回退默认值并正常渲染(不报错弹窗)。
- 快速拾取窗口(quickpick)不加载命令面板与速查表(main.tsx 分流已保证,无需改)。
- 设置弹窗打开时按 Ctrl+K/? 不打开新面板;面板打开时多选快捷键与 Ctrl+N/F 均不生效。
- 输入中文触发组字时 Ctrl+K/? 不响应。
