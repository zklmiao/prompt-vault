【任务】A4 · 列表→详情级联淡入,并把项目版本号升到 0.1.9。

【项目背景】项目在 <项目根目录>(Tauri 2 + React 19 + TS)。详情面板在 src/components/DetailPane.tsx:视图分支是 `<section className="detail"><div className="detail-inner">…`,子元素依次为 detail-head(标题+置顶)、detail-tags(条件)、ph-badge(条件)、detail-line 来源(条件)、detail-line 备注(条件)、pre.body-view、detail-actions、meta。样式全部走 src/App.css 的 CSS token(light/dark),已存在全局 prefers-reduced-motion 降级块(App.css 约 1354 行)。禁止引入依赖。

【需求】
1. 选中条目时,详情内容按 20ms 阶梯从下方 6px 淡入(opacity 0→1 + translateY 6px→0,时长约 260ms,缓动 ease)。
2. 仅视图分支生效;编辑器(new/edit)与空态、回收站空态不参与。
3. 切换不同条目时动画重新开始;同一 ID 的重渲染(置顶切换、复制计数刷新等)不重放。
4. 遵循系统“减少动态效果”设置。

【实现要点】
- DetailPane.tsx 视图分支容器改为:`<div className="detail-inner stagger" key={item.id}>`(key 用于切换条目时重放动画;不要给编辑器和空态加 stagger)。
- App.css 新增:
  @keyframes pv-detail-in { from { opacity: 0; transform: translateY(6px); } to { opacity: 1; transform: translateY(0); } }
  .detail-inner.stagger > * { opacity: 0; animation: pv-detail-in 0.26s ease forwards; }
  .detail-inner.stagger > *:nth-child(1) { animation-delay: 0ms; }
  … nth-child(2..8) 依次 20ms 递增(20/40/60/80/100/120/140ms)。用 nth-child,不要改 JSX 子元素。
- 扩展已有的 prefers-reduced-motion 块,补一行 `animation-delay: 0ms !important;`(现有块只覆盖了 duration,不改会让减弱动效用户出现最长 140ms 的空白)。
- 不要动画化 .body-view 内部文本或按钮 hover 过渡;不新增 JS 计时器;不改变布局尺寸。
