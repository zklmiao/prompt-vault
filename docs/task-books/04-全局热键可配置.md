【任务】把 Prompt Vault 硬编码的全局热键(Alt+Q 快速拾取、Alt+Shift+N 剪贴板速存)改成用户可配置,并在应用内加设置入口。

【项目背景】项目在 <项目根目录>,Tauri 2 + React 19 + TS。lib.rs 现状:run() 里 "alt+q"/"alt+shift+n" 解析成 Shortcut,plugin(tauri_plugin_global_shortcut::Builder::new().with_handler(...)) 比较捕获的 clone 来分发 toggle_quickpick / clipboard_new,setup 中 register。配置在 <用户配置目录>/prompt-vault/config.json(结构见 lib.rs 的 AppConfig,含 data_path 与 window)。界面 header 在 src/App.tsx,图标集 src/components/icons.tsx,弹窗基座 src/components/Modal.tsx(自带 focus trap 与 Esc)。

【需求与交互设计】
1. 配置结构:AppConfig 增加 hotkeys: Option<HotkeyConfig>,HotkeyConfig { quickpick: String, clipboard_new: String },缺省 alt+q / alt+shift+n。
2. 新 Rust 命令:
   - get_hotkeys() -> { quickpick, clipboard_new }(缺省时返回默认值);
   - set_hotkeys(quickpick: String, clipboard_new: String) -> Result<(), String>:解析两个字符串(Shortcut::from_str,支持 "alt+shift+q" 等),失败返回可读错误;先注销旧键、注册新键,任一注册失败则回滚(注销新键、恢复旧键)并返回「组合键无法注册,可能已被系统或其他应用占用」;成功才写入 config.json。
   - 热键当前值放全局 static Mutex<Option<(Shortcut, Shortcut)>>,handler 里加锁比较(不要继续依赖捕获的闭包变量,否则设置后不生效)。
3. 前端设置入口:header 右上角(主题切换旁)加齿轮图标按钮(icons.tsx 新增 IconSettings),打开 SettingsModal(复用 Modal):
   - 两个热键捕获输入框:「快速拾取」「剪贴板新建」。点击输入框开始捕获,keydown 组合键 → 显示为 "Alt+Q" 形式,内部保存 Tauri 格式小写 "alt+q";仅按修饰键时显示等待;Esc 取消捕获(不关闭弹窗,事件 stopPropagation);要求至少一个修饰键(Ctrl/Alt/Shift/Win),否则提示「请包含至少一个修饰键」。
   - 保存:invoke set_hotkeys,成功 toast「热键已更新,立即生效」并刷新显示;失败显示 Rust 返回的错误,保留旧值。
   - 「恢复默认」按钮:回填 alt+q / alt+shift+n 并保存。
4. README 快捷键章节、快速拾取占位文案(QuickPick.tsx 的 placeholder 提到 Esc)保持不变,但 README 增加「可在设置中修改」;设置弹窗里实时显示当前生效值(get_hotkeys 初始化)。

【实现要点】
- 前端键名映射:event.ctrlKey→ctrl、altKey→alt、shiftKey→shift、metaKey→super;主键用 event.key 小写(字母取 e.code 更稳,如 KeyQ→q;F1-F12 直接用 key)。禁止单独的数字/字母/功能键(必须带修饰键)。保留键如 Tab、Escape 不允许作为唯一主键。
- lib.rs:解析失败的错误信息带上输入值,便于用户理解;注册/注销顺序不可颠倒;回滚路径要测试。
- 设置弹窗打开时不影响现有快捷键监听(App.tsx 的 window keydown 只在输入框外生效,注意热键捕获框要 stopPropagation)。
- 兼容:浏览器预览无 Tauri 事件系统,SettingsModal 的 invoke 会失败——包 try/catch,预览环境显示「仅打包版可用」。

【边界与异常】
- 新热键被占用:提示且旧键继续有效(config 不写)。
- 两个热键设置相同:前端拦截并提示「两个功能不能使用同一组合键」。
- 修改后无需重启即生效;重启后从 config 读回并注册。
- 若 config 中的键无法解析(手改坏):启动时回退默认值,不崩溃。

【不要做的事】
- 不要引入快捷键录入库;不要做热键与系统键冲突的自动探测(注册失败即冲突);不要动托盘逻辑。
