【任务】A7 · 首次启动引导(空态 3 步卡片,可跳过),并确保项目版本号为 0.1.9。

【项目背景】项目在 <项目根目录>(Tauri 2 + React 19 + TS)。空态渲染在 src/components/DetailPane.tsx 的 `if (!item)` 分支(内含现有插画与“还没有收藏”文案);列表为空但未选中时也用同一分支。App.tsx 持有 liveItems、startNew、prefill 机制(useState<NewPrefill|null> + prefillSeq)与 handleSave。src/types.ts 的 NewPrefill 目前只有 title/body/source;src/components/DetailPane.tsx 的 draftFrom 只回退 title/body/source。热键读取用 src/api.ts 的 getHotkeys();格式化逻辑目前是 src/components/SettingsModal.tsx 内的局部 displayOf。localStorage 既有键:pv-theme、pv-sort。所有按键相关改动不得影响既有行为;禁止引入依赖。

【需求与交互】
1. 触发:仅当“没有数据(不含回收站条目)且未跳过引导”时,右侧空态显示 3 步引导卡片;回收站为空时仍显示现有回收站空态;有数据但未选中时仍显示现有“在左侧选择一条收藏查看详情”空态。
2. 卡片内容(中文,三列自适应,窄窗纵向堆叠;全部使用现有 token,无外部图片):
   第 1 步「收集」:说明可新建收藏;按钮「新建第一条」→ 进入空白新建编辑态。
   第 2 步「试占位符」:说明正文写 {{变量}} 复制前可填空;按钮「创建示例」→ 以预填方式新建一条示例(标题「示例:代码审查助手」,正文:
   请审查以下代码变更:{{diff}}
   
   重点关注:{{关注点}}
   
   输出:问题清单、改进建议、是否可合并。
   source「引导示例」,tags [「示例」])。
   第 3 步「随叫随到」:展示动态热键(如 Alt+Q)与一句“任意界面唤起快速拾取”;热键从 getHotkeys() 读取,失败回退 alt+q。
   卡片底部右侧一个“跳过引导”文字按钮。
3. 跳过/完成规则:点击“跳过引导”置位 localStorage 键 "pv-onboarded" = "1";任意新建保存成功后也置位(避免删除全部条目后引导反复出现);已置位则永不显示。
4. 引导出现/消失不做花哨动画,沿用现有过渡即可。

【实现要点】
- 新建 src/components/Onboarding.tsx:props 为 { onSkip, onCreateFirst, onCreateSample };内部 useEffect 调 getHotkeys() 并 formatHotkey 显示,失败回退默认。
- src/util.ts 新增 formatHotkey(hotkey: string): string(把 SettingsModal 的 displayOf 逻辑搬来),SettingsModal 改为使用它,消除重复。
- src/types.ts:NewPrefill 增加可选 tags?: string[]; note?: string;;DetailPane 的 draftFrom 增加 `tags: item?.tags ?? prefill?.tags ?? []` 与 `note: item?.note ?? prefill?.note ?? ""`(保持向后兼容)。示例条目即通过该扩展带标签。
- App.tsx:新增 onboarded 状态(初始化读 localStorage,读取异常按未读处理)与 handleSkipOnboarding;新增 handleCreateSample(设置 prefill 并进入新建);在 handleSave 的新建分支成功 persist 后写 localStorage("pv-onboarded","1") 并更新状态;计算 showOnboarding = !trashOpen && !onboarded && liveItems.length === 0,传给 DetailPane。
- DetailPane.tsx:新增可选 props { onboarding: OnboardingProps | null },空态分支内 onboarding 非空时渲染 <Onboarding … /> 替代现有插画与文案,否则保持现状。
- preview/mock-core.ts(dev 夹具,不参与构建):支持 URL 参数 ?empty=1 时返回空 prompts 数组,便于预览验证引导;不要影响正常预览数据。
- 版本号:package.json、src-tauri/tauri.conf.json、src-tauri/Cargo.toml 统一为 0.1.9(若 A4 已升到 0.1.9 则跳过);不改 README 下载资产名;交付说明里提醒发布 v0.1.9 Release 时再对齐 README。

【边界与异常】
- 浏览器预览中 getHotkeys 会失敗:回退默认热键并正常渲染,不弹错误。
- localStorage 不可用:引导仍然可用,只是不记忆(不崩溃)。
- 用户在引导可见时按 Ctrl+N 直接新建并保存:引导消失且不再出现。
- 引导卡片在暗色/亮色下对比度正常;窗口最小宽度(800)下三列自动堆叠为单列。
- 不改动快速拾取窗口、命令面板、搜索与排序逻辑。
