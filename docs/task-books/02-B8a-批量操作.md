# B8a 批量操作（任务书全原文）

---

【任务】给 Prompt Vault 的列表加多选与批量操作:批量打标签、批量移入回收站、批量导出所选;回收站内支持批量恢复与批量彻底删除。

【项目背景】项目在 <项目根目录>,Tauri 2 + React 19 + TS,两栏界面:src/components/Sidebar.tsx 列表行、src/components/DetailPane.tsx 详情/编辑、src/App.tsx 管状态(items、selectedId、mode、trashOpen、filtered 等)。现有删除是软删除(deletedAt),回收站可恢复/彻底删除;导出是 App.tsx 的 handleExport(chooseExportFile + serializeDataFile(items) 写文件)。行上已有 hover 复制按钮(.row-copy)。图标在 src/components/icons.tsx。

【需求与交互设计】
1. 多选状态:App 新增 selectedIds: Set<string>。
   - 每行左侧出现 checkbox(仅在鼠标 hover 行或已有选中时淡入,参考 .row-copy 的交互);Ctrl+点击行 = 切换多选;Shift+点击 = 连选当前列表区间;普通点击 = 清空多选并正常单选。
   - 多选非空时右侧详情面板替换为「已选 N 条」操作面板:批量加标签输入框(沿用 TagInput 组件)、批量移入回收站(软删)、批量导出 JSON、全选、取消选择。
   - Ctrl+A 全选当前列表;Esc 清空多选(不与弹窗 Esc 冲突,弹窗优先)。
2. 批量加标签:输入若干标签,对选中项追加(去重,保留原标签);完成后 toast「已为 N 条添加标签」;若输入为空禁用按钮。
3. 批量移入回收站:直接软删(不弹确认,回收站本就是安全网),清空 selectedIds,toast。
4. 批量导出:只导出选中项,chooseExportFile("prompt-vault-selection.json") + serializeDataFile(selected),toast「已导出 N 条」。
5. 回收站视图(trashOpen):
   - 支持多选;面板按钮改为「批量恢复」「批量彻底删除」。
   - 批量彻底删除必须 ConfirmModal,文案含条数:「确定彻底删除选中的 N 条?不可恢复。」
6. 多选状态下隐藏行内复制按钮(避免与选择冲突);单行详情保持原行为。

【实现要点】
- selectedIds 用 Set<string>,所有切换操作产生新 Set(React 不可变更新)。
- filtered 的列表顺序用于 Shift 连选区间;连选基于当前 filtered 数组的索引。
- Sidebar 新增 props:selectedIds、onToggleSelect(id, modifiers)、onSelectRange(fromId, toId) 或统一 onRowClick(id, event)。
- 批量面板做成 DetailPane 的一个分支(当 selectedIds.size>0 时优先渲染),或独立组件 BatchPanel.tsx;不要塞进 Editor 分支。
- 批量操作后统一走 persist(next),与现有写盘逻辑一致。
- 图标:批量面板按钮复用/新增 Trash、Undo、Export、Tag 图标。

【边界与异常】
- 切换视图(回收站开/关)时清空 selectedIds。
- 当前选中的单条被批量删除后,清空 selectedId 与 mode。
- 全选只选当前 filtered(受搜索/标签筛选影响),不是全库——在按钮 title 里说明。
- 空列表时全选按钮禁用。

【不要做的事】
- 不要做拖拽排序、不要做跨视图混合选择;不要改数据格式。
